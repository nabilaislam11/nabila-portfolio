Scope and capabilities of the later reference build

The current NASM source checks a minimum length and the presence of uppercase, lowercase, numeric, and non-alphanumeric ASCII characters, with rule-specific feedback and process exit statuses.

Technology of the later reference build

NASM · x86-64 Linux · System calls

Implementation approach

The implementation is intentionally small and demonstrates low-level control flow and character classification. It is a password policy checker only: it does not store credentials, hash passwords, authenticate users, or protect terminal input from echo.

Validation and limitations

Current validation status

GitHub Actions successfully assembled and linked the NASM source on Ubuntu and passed 5 policy smoke tests covering valid input, missing character classes, short input, and empty input. Terminal echo is enabled; use dummy test strings only. This remains an educational policy checker, not a secure authentication system.

Running or reproducing the project

On a compatible x86-64 Linux system with NASM and binutils installed, assemble and link the source using the commands in the project README, then run it with dummy input.
