# CampusDesk — School Management System

A reconstructed web application inspired by the academic project title **Advanced School Management System**.

## Reference implementation
- Python and Flask
- Flask-SQLAlchemy and SQLite
- Flask-Login and role-aware access
- Flask-WTF CSRF protection
- Student and teacher records
- Class, section and subject management
- Attendance, examinations, results and fee records

## Scope and provenance
This is a newly written reference implementation, not a verified reproduction of the original university source code. The feature list describes this reconstructed application and should not be interpreted as a claim that every feature existed in the historical submission.

## Validation status
Python syntax compilation and static checks were performed. Full runtime, database integration, authorization and browser testing remain pending because the required Flask dependencies could not be installed in the build environment.

See the local project package for setup instructions, database design, test plan and implementation limitations.
