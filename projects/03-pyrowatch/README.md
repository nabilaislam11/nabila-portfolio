# PyroWatch — Fire and Smoke Detection

A reconstructed image-analysis application inspired by the academic project title **Advanced Fire and Smoke Detection System**.

## Reference implementation
- Python and Flask web interface
- Image upload and validation
- Detection history and analysis records
- Optional YOLO model integration through configured model weights
- Annotated image output when a compatible model is available

## Scope and provenance
This is a newly authored reference implementation, not a verified reproduction of the original academic source code. No trained model weights or fabricated detection outputs are included. Actual inference requires a compatible model supplied by the user.

## Validation status
Static Python and form checks were performed. Runtime application testing and real model inference remain pending.
