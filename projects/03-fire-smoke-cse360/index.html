Advanced Fire and Smoke Detection System

An Arduino-based academic fire-alarm project documented through a project report and supporting hardware software materials.

Project overview

The system studies fire and smoke detection with microcontroller control logic and an alarm response. The group report records the design and coursework materials.

Project materials

The academic repository contains the CSE360 report, fire-alarm software archive, another project source archive, and an Arduino LCD library archive.

Technology

Arduino · Microcontroller programming · Fire and smoke sensing · Alarm systems

Related implementation

The separate PyroWatch web application explores image-based detection with a Python/Flask interface.
