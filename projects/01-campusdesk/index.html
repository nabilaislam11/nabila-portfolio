Advanced School Management System

A school administration reference application designed around the everyday records and workflows of a school.

RECONSTRUCTED REFERENCE IMPLEMENTATION

Project context

This page distinguishes the original academic group project from a separately authored, later portfolio reference implementation.

Original academic project and evidence

The original group repository contains a Laravel 8 / PHP application with student, timetable, and school administration modules.

View original group-project materials ↗

This was collaborative academic work. Individual responsibilities have not yet been verified.

Scope and capabilities of the later reference build

The application is organised into student and teacher records, class and subject setup, daily attendance, examination scheduling, result entry, and fee invoice/payment records.

Technology of the later reference build

Python · Flask · Flask-SQLAlchemy · Flask-Login · Flask-WTF · SQLite

Implementation approach

The application uses a Flask application factory, SQLAlchemy relational models, role-aware route protection, CSRF-protected forms, and server-rendered templates. The database models connect students to classes, attendance to students, results to exams, and payments to invoices.

Validation and limitations

Current validation status

The latest GitHub Actions run passed 5 automated tests, including login/dashboard checks, selected administration-page rendering, and grade calculation. Python compilation also passed. Full browser workflows, migration behaviour, and deeper authorization-boundary testing remain outstanding.

Running or reproducing the project

Create a virtual environment, install requirements.txt, configure a strong SECRET_KEY, create the first administrator account using the documented setup workflow, and run run.py. Do not deploy with the development secret or debug mode.
