# ShelfWise — Book Shop Management System

A reconstructed reference application inspired by the academic project title **Advanced Book Shop Management System**.

## Reference implementation
- Python, Flask, SQLAlchemy and SQLite
- Role-aware admin and staff access
- Book catalogue and ISBN tracking
- Stock adjustment and low-stock monitoring
- Customer records and multi-item sales
- Discount/tax calculations and invoice output
- Transaction-oriented stock validation

## Scope and provenance
This is a new portfolio implementation, not a verified copy of the original academic submission. The features above refer to the reconstruction only.

## Validation status
Static source checks were performed. Runtime application and automated test execution remain pending because the build environment could not install the Flask dependencies.

See the local project package for setup, architecture, database design, test plan and known limitations.
