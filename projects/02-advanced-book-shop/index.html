ACADEMIC GROUP PROJECT · CSE370 · PHP / MYSQL

Advanced Book Shop Management System

A database-backed bookshop system combining customer orders, product inventory, and administrative operations.

Overview

The course project implements an online book ordering and delivery workflow, with a catalogue, user accounts, cart, inventory records, and an administrative interface.

Database design

MySQL/MariaDB tables connect books and inventory with shopping carts, customers, orders, and order items. A SQL schema reference is included with the academic project materials.

Technologies

PHP · MySQL/MariaDB · HTML · CSS · JavaScript · XAMPP
