Context-Aware Hate Speech Detection with CNN

A reference machine-learning pipeline exploring how surrounding text context can be incorporated into a CNN-based text classification task.

RECONSTRUCTED REFERENCE IMPLEMENTATION

Project context

Inspired by the academic project topic CNN-based Approaches for Contextual Hate Speech Detection. The original dataset, trained weights, and experimental records are not available, so this implementation is presented as a new baseline rather than a reproduction.

Scope and capabilities

The pipeline expects post text, conversational context, and labels; combines text with explicit context markers; tokenises and pads sequences; and defines parallel one-dimensional CNN branches for classification. It includes a separate prediction script.

Technology

Python · TensorFlow / Keras · NumPy · Pandas · scikit-learn

Implementation approach

The project separates training and prediction scripts and exports model artefacts and evaluation outputs when trained with a suitable dataset. It includes no dataset, pretrained weights, benchmark score, or fabricated result.

Validation and limitations

Current validation status

Python syntax compilation passed. Training and inference have not been run because no dataset or trained model was supplied. Evaluation should use conversation- or author-grouped splits where appropriate and report macro-F1 and per-class metrics.

Running or reproducing the project

Install the pinned dependencies, prepare a CSV with the documented text/context/label fields, review the train/test split strategy, run the training script, then use the prediction script with the generated artefacts.
