LOW-LEVEL PROGRAMMING · NASM / X86-64

Assembly Password Policy Checker

A command-line NASM program for evaluating password strings against a defined set of character and length rules.

Project overview

This exercise uses x86-64 Linux assembly and system calls to read test input, classify characters, and report whether the input meets a simple password policy.

Implementation

The checker examines minimum length and the presence of uppercase, lowercase, numeric, and special characters and returns rule-specific feedback. Its purpose is policy evaluation, rather than storing or authenticating user credentials.

Technologies

NASM · x86-64 Linux · Linux system calls

Automated tests

GitHub Actions assembles and links the program and runs five smoke tests covering valid and invalid inputs.

Run locally

The checker builds on Linux with NASM and the system linker. The README includes a sample run and test commands.
