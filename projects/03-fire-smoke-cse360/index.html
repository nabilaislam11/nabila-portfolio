Advanced Fire and Smoke Detection System

An Arduino-based academic fire-alarm project documented through a project report and supporting hardware software materials.

Project overview

The system studies fire and smoke detection with microcontroller control logic and an alarm response. The group report documents the system design and implementation.

Project materials

The project materials include the original group project report, the Arduino fire-and-smoke sketch, the serial communication prototype, and an original project archive.

Technology

Arduino · Flame and smoke sensors · Buzzer and LED indicators · I²C LCD · Serial communication

Related implementation

The separate PyroWatch web application explores image-based detection with a Python/Flask interface.
