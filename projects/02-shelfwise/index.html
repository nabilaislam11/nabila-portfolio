ShelfWise — Book Shop Management System

A Flask application for cataloguing books, managing inventory, and recording customers, sales, and invoices.

Application overview

ShelfWise brings together book catalogue records, stock quantities, customer accounts, multi-item sales, and invoice generation in one web interface.

Implementation

The Flask backend separates database models, sales services, and web routes. Decimal arithmetic is used for discounts and taxes, while sales validation checks stock availability before finalizing transactions.

Technologies

Python · Flask · SQLAlchemy · SQLite · Decimal

Automated tests

The repository includes six passing automated tests for sales calculations, inventory updates, insufficient-stock validation, and authenticated page rendering.

Application features

ShelfWise uses Flask and SQLAlchemy to manage inventory, checkout, and invoices. It includes an administrator interface.
