Advanced Fire and Smoke Detection System

An image-analysis workflow designed to connect a web interface with a configurable fire/smoke detection model.

RECONSTRUCTED REFERENCE IMPLEMENTATION

Project context

This page distinguishes the original academic group project from a separately authored, later portfolio reference implementation.

Original academic project and evidence

The original CSE360 group repository contains a computer-interfacing project report and archived source files. Its precise architecture needs verification from the report; it must not be described as a YOLO project without evidence.

View original group-project materials ↗

This was collaborative academic work. Individual responsibilities have not yet been verified.

Scope and capabilities of the later reference build

The current reference build provides authenticated media submission, image-type validation, analysis records, a detection history, and an optional adapter for compatible YOLO model weights. Annotated output is saved when inference runs successfully.

Technology of the later reference build

Python · Flask · Ultralytics YOLO adapter · OpenCV (optional)

Implementation approach

The inference adapter loads weights from MODEL_PATH rather than bundling an unverified model. Uploads receive generated storage names and are associated with analysis records. Video files can be recorded but video inference is not implemented in this version.

Validation and limitations

Current validation status

The latest GitHub Actions run passed 3 automated tests, covering login/dashboard rendering, unsupported-file rejection, and analysis/record-detail page rendering. Actual model inference has not been run because no verified weights or dataset were supplied. No detection accuracy or performance results are claimed.

Running or reproducing the project

Install the web dependencies. For inference, separately install compatible Ultralytics and OpenCV packages, provide a verified model weights file, and set MODEL_PATH. Test only with appropriately licensed sample media.
