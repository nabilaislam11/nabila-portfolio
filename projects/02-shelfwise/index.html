Advanced Book Shop Management System

A bookshop workflow reference build connecting catalogue records, stock, customers, and sales.

RECONSTRUCTED REFERENCE IMPLEMENTATION

Project context

This page distinguishes the original academic group project from a separately authored, later portfolio reference implementation.

Original academic project and evidence

The original group repository contains a PHP/MySQL book-ordering application, an SQL schema, and administrative workflows.

This was collaborative academic work. Individual responsibilities have not yet been verified.

Scope and capabilities of the later reference build

The reference scope includes ISBN-based catalogue records, stock quantities and low-stock thresholds, customer records, multi-item sales, discount and tax calculations, invoice records, and stock validation during sale creation.

Technology of the later reference build

Python · Flask · SQLAlchemy · SQLite · Decimal arithmetic

Implementation approach

The backend separates database extensions, models, sales services, and web routes. Monetary calculations use Decimal rather than binary floating-point arithmetic. Sale creation validates quantities and available stock before committing the transaction.

Validation and limitations

Current validation status

The latest GitHub Actions run passed 6 automated tests, covering Decimal totals, discount validation, stock reduction, insufficient-stock handling, and authenticated route/template rendering. Concurrent inventory behaviour on a production database, payment integration, and full browser testing remain outstanding.

Running or reproducing the project

Install requirements.txt in a virtual environment, configure the application secret and database URL, initialise the database, create an administrator account, and start run.py. Use fictional data for demonstrations.
