PyroWatch — Fire & Smoke Image Analysis

An image-analysis application connecting authenticated media submission, analysis records, and optional model inference.

Application overview

The web interface supports media submissions, upload validation, analysis history, and detailed results pages. A configurable YOLO integration connects image processing with an externally supplied fire-and-smoke model.

Architecture

Flask routes handle the user interface and records; a separate detection adapter provides the model-loading interface. Model configuration uses an external path rather than bundling weights with the web application.

Technologies

Python · Flask · YOLO inference adapter · OpenCV

Automated tests

Three automated tests cover authentication and dashboard rendering, unsupported-file rejection, and analysis-record page rendering.

Image inference

PyroWatch uses Flask for the web interface and analysis records. An optional computer vision adapter supports image inference with compatible model weights.
